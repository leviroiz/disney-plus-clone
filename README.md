# 🏰 Disney+ Clone

Clone da página inicial do Disney+, desenvolvido de forma independente após estudos com HTML e CSS.

---

## 🖥️ Sobre o projeto

Recriação da landing page do Disney+ Brasil, feita por conta própria com base no conhecimento adquirido em projetos anteriores. Foco em fidelidade visual, tipografia customizada e detalhes de UI.

---

## ✨ Funcionalidades

- Layout fiel à página original do Disney+
- Fonte customizada com `@font-face` (Avenir Roman)
- Botões com transição de hover suave
- Seção de preços com planos mensais e anuais
- Logo das franquias (Marvel, Star Wars, Pixar...)
- Botão de entrar com efeito invertido no hover

## 📚 O que aprendi

- Uso de fontes customizadas com `@font-face`
- Flexbox para layouts lado a lado
- Transições CSS para interatividade
- Seletores CSS avançados (`.preco + .preco`)
- Posicionamento com `position: absolute`
- Evolução na organização e limpeza do código
